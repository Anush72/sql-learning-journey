## 📅 Daily Progress

| Day / Topic | Topic Learned | Key Concepts / Highlights |
| :---: | :--- | :--- |
| **Lesson 01** | Tables & Basic Queries | Table creation, row insertion, filtering with `WHERE`, sorting with `ORDER BY`, pattern matching using `LIKE` and `ILIKE` |
| **Lesson 02** | Data Types & Type Casting | `char`, `varchar`, `text`, `integer`, `serial`, `decimal`, `timestamp`, `interval`, `json` vs `jsonb`, explicit casting using `CAST()` and `::` |
| **Lesson 03** | Importing & Exporting Data | Importing CSV files into tables, copying specific sub-columns, and exporting database query results using `COPY` |
| **Lesson 04** | Basic Math & Statistics | Arithmetic following BODMAS rules, descriptive statistics with `avg()`, `mode()`, and calculating percentiles/quartiles with `percentile_cont()` |
| **Lesson 05** | Table Joins & Relationships | `INNER`, `LEFT`, `RIGHT`, `FULL OUTER`, and `CROSS` joins; understanding One-to-One, One-to-Many, and Many-to-Many relationships |
| **Lesson 06** | Naming Guidelines | Identifier best practices: using `snake_case`, plural table names, clear non-cryptic names, and sensible backup table naming |
| **Lesson 07** | Constraints & Indexing | Primary Keys (Natural, Surrogate, Composite), Foreign Keys with `CASCADE`, `CHECK`, `UNIQUE`, `NOT NULL`, and speed optimization using Indexes |
| **Lesson 08** | Aggregate Functions | Grouping data with `GROUP BY` and aggregating with `COUNT()`, `MIN()`, `MAX()`, and `SUM()` |
| **Lesson 09** | Inspecting & Modifying Tables | Checking for `NULL` values and inconsistencies, altering/dropping tables, safe backups, and using `BEGIN`, `COMMIT`, `ROLLBACK` transactions |
| **Lesson 10** | Statistics & Window Functions | Correlation, linear regression calculations, and ranking rows using `RANK()` and `DENSE_RANK()` window functions |
| **Lesson 11** | Date and Time | Timestamp, Local Zone, Extracting Day, Month, Time|
| **Lesson 12** | Advanced Query Techniques | Subquery, Using Where Clause, Derived Tables, Joining Tables, Making Columns|
